## 这是什么

写短剧最费劲的从来不是某一步，而是那七八步之间的来回搬运：设定在一处、大纲在另一处、图生成完再手动改名搬到剪辑软件里。

海森短剧把这些塞进同一个工作台：**项目 → 剧本 → 资产 → 分镜 → 画布 → 剪辑 → 配乐 → 输出 → 宣发**。九块内容共用同一套工程目录，改一处，下游拿到的就是改过的那份。

- **工程即文件夹**：每个项目就是磁盘上的一个文件夹，剧本、设定、素材、成片都在里面，随时能整个拷走。
- **AI 只做它擅长的**：文字、图片、视频按需接入；要不要用、用哪家，自己定。
- **成片真出得来**：播放走 libmpv 硬解直上屏，输出走 ffmpeg，字幕可以直接烧进画面。

## 下载安装

1. 打开 [Releases](https://github.com/pusijia/Haiseng-Studio/releases/latest)，下载最新的 **`HaisengDrama-Setup-x.y.z.exe`**。
2. 双击安装。装到当前用户目录，**不需要管理员权限**。
3. 装完自动启动，直接能用。

> 安装包里已经带好播放内核与转码工具，不用另外装运行库、不用配环境变量。
>
> 首次启动可能会被 SmartScreen 提示「未知发布者」，因为安装包没有购买代码签名证书。点「更多信息 → 仍要运行」即可。

## 九个模块，串成一条流水线

| 模块 | 做什么 |
| :--- | :--- |
| **项目** | 一个项目一个文件夹，名称即剧本名。封面、进度、最近打开都在这里。 |
| **剧本** | 五步创作：创建剧本 → 大纲 → 角色 → 剧情走向 → 正文。逐集正文按「第 NN 集」分目录落盘。 |
| **资产** | 角色、场景、道具、生物……按类目归档，每类都有对应的图面设定表版式（三视图、七区设定表等），一键生成设定图。 |
| **分镜** | 一场戏拆成镜号，逐镜写画面提示词、挂参考资产，直接出分镜画面与视频片段。 |
| **画布** | 自由摆放的节点画布，用来推镜头关系、试构图；节点可以直接出图、图生视频。 |
| **剪辑** | 多轨时间线 + 素材池：切片、变速、音轨增益、字幕样式，边剪边看。 |
| **配乐** | 给成片铺音乐与音效，波形对齐时间线。 |
| **输出** | 把选中的时间线渲染成 MP4：画面、音轨、变速、烧进画面的字幕一起出。 |
| **宣发** | 项目封面、宣传海报、爆款喜报、定档物料、角色海报，成品统一落在项目的「海报」目录。 |

### 剧本的五步

```
创建剧本  →  大纲  →  角色  →  剧情走向  →  正文
```

每一步的产物都是结构化的：大纲按集拆条，角色带人设与外观描述，剧情走向可分支对比，正文按集写。后面的资产与分镜直接从这里取名字和设定，不用重新录一遍。

## 更新

应用内会自动检查新版本：发现后右下角提示，点开即下载安装。也可以从**底栏左下角账号菜单 → 检查更新**手动触发。

下载线路可以在**设置 → 更新**里挑：内置了一批国内加速前缀，支持测速、指定线路，也可以自己添加。线路连不上会自动换下一条，版本号与校验值始终以 GitHub 为准。

## 常见问题

<details>
<summary><b>安装包提示「未知发布者」，能装吗？</b></summary>

能。安装包没有购买代码签名证书，Windows 会按未签名程序处理。点「更多信息 → 仍要运行」继续；介意的话可以先核对 Release 页面上公布的 SHA-256。

</details>

<details>
<summary><b>卸载会删掉我的工程吗？</b></summary>

不会。工程数据放在用户数据目录里，卸载只移除程序本体。需要彻底清理时手动删该目录即可。

</details>

<details>
<summary><b>为什么只有 Windows 版？</b></summary>

播放与渲染依赖 Windows 上的原生窗口与解码链，目前只做了 Windows 的完整实现。

</details>
